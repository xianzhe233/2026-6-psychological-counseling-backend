## 当前风险

1. 多角色权限和数据归属校验较多，需在 Service 层严格控制。
2. 预约容量和时间冲突需要事务保证，不能只做前端校验。
3. 咨询安排涉及咨询师、学生和咨询室冲突，必须由后端统一校验。
4. 结案报告 Word 导出格式可能需要较多调试时间。
5. 统计接口依赖演示数据，需提前准备 `demo_data.sql`。
6. 若使用 Spring Boot 3，则团队环境需统一 JDK 17。
