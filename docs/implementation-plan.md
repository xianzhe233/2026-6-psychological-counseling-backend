# 后端实施计划

> 本计划用于指导后端从空仓库落地到可演示系统。每个阶段应形成可运行、可联调、可提交的小成果。

---

## 1. 初始化阶段

### 1.1 创建 Spring Boot 工程

建议配置：

- GroupId：`com.tyut`
- ArtifactId：`psychological-counseling-backend`
- Package：`com.tyut.psychological`
- Java：17
- Build：Maven

依赖：

- Spring Web
- MyBatis Framework
- MySQL Driver
- Validation
- Lombok（可选）
- Apache POI（导出阶段添加）

验收标准：

- `mvn spring-boot:run` 可启动。
- `/api/health` 返回成功。
- 连接 MySQL 成功。

### 1.2 配置 application.yml

完成：

- server port。
- datasource。
- MyBatis mapper 路径。
- session timeout。
- Jackson 时间格式。

## 3. 阶段二：数据库和初始数据

任务：

## 4. 阶段三：登录与用户模块

任务：

1. `AuthController`。
2. `AuthService`。
3. `UserController`。
4. `UserService`。
5. `StaffProfileService`。
6. 用户分页、新增、编辑、启用、禁用、重置密码。

任务：

## 12. 联调与测试阶段

后端自测重点：

1. Session 登录：未登录、已登录、角色不匹配。
2. 初访预约：未登记、未签署、重复预约、容量不足。
3. 审核：通过、驳回、改约、优先。
4. 初访结果：无需咨询、安排咨询、转介送诊。
5. 咨询安排：正常安排、咨询师冲突、学生冲突、咨询室冲突。
6. 咨询记录：完成、旷约、请假、结案。
7. 结案报告：草稿、提交、导出。
8. 统计：有数据、无数据。

建议使用 Postman 或 HTTP Client 保存接口测试用例。
